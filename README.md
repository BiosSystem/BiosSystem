## What I Build

High-performance web frontends, systems tooling, real-time analytics platforms, game server emulators, desktop applications, and automated utilities.

---

## Open-Source Public Projects

- **[AuraTorrent](https://github.com/BiosSystem/AuraTorrent)**: A lightweight, responsive Vue 3 PWA designed as a complete alternative WebUI for qBittorrent. Features drag-and-drop RSS management, custom rule filtering, multi-server switching, and automated Telegram bot delivery notifications.
- **[Winnow](https://github.com/BiosSystem/Winnow)**: A modular PowerShell debloat and Windows optimization toolkit. Supports safe audit modes, granular feature toggles, telemetry removal, and exportable JSON configuration profiles with zero runtime registry bloat.
- **[retro-game-replicas](https://github.com/BiosSystem/retro-game-replicas)**: A cross-platform desktop arcade launcher built with Tauri v2, Phaser 3, and TypeScript. Bundles 11 classic arcade games with custom GLSL CRT post-processing shaders, native HTML5 Gamepad API co-op support, and persistent local score tracking.
- **[OriginalMS](https://github.com/BiosSystem/OriginalMS)**: A full-fidelity MapleStory v62 (GMS 2008) server emulator in Java and MySQL, running over Apache MINA. Fully scripted party quests, boss instances, Cygnus Knights, and Aran classes, packaged in Docker for one-command local hosting.

## Featured Engineering Portfolio

### Gaming Telemetry & Desktop Systems
- **StatZilla**: High-performance mobile game statistics tracker and telemetry engine built with React 19 and TypeScript. Connects directly to official game developer APIs (Brawl Stars, Clash Royale, PUBG Mobile) to deliver real-time player profiles, win-rate analytics, historical battle logs, trophy progress, and global rankings.
- **Therm Studio (Cpu-LCD-Therm)**: Local-first creator suite and hardware display engine for USB CPU-cooler LCD panels (320x320). Converts panels into customizable real-time sensor dashboards, layered media canvases, hardware telemetry gauges, and interactive streaming displays without vendor background bloat.
- **OutbreakRP**: Custom multiplayer survival roleplay framework for the FiveM platform. Features modular faction progression systems, infection and survival mechanics, dynamic loot economy, and safehouse construction systems.

### Network Tooling & Web Services
- **Steady (SpeedTest)**: Self-hosted network performance and bandwidth measurement console. Executes high-precision download/upload throughput tests, loaded latency, tail latency, jitter, ping, and UDP packet loss analysis without third-party API dependencies. Stores long-term telemetry in SQLite WAL mode with automated background scheduling.
- **Sniplink**: Privacy-first URL shortening service engineered with custom alias routing, link expiration timelines, password-protected redirects, and click telemetry analytics. Includes built-in sliding-window rate limiting and automated anti-abuse filtering.
- **TorrentsTracker**: Private invite-based BitTorrent tracker platform with an end-to-end TypeScript architecture. Features a high-throughput NestJS API, announce/scrape daemon, PostgreSQL data layer with Prisma ORM, and a Next.js App Router member portal.

### AI Governance & Platforms
- **OmniToken Suite**: Dual-tier AI token metering, telemetry, and cost governance architecture. Features an offline-first Python ingestion engine that decodes protobuf and wire logs with monotonic high-water ratchets (`omni-token-telemetry`), paired with a Next.js 15 App Router executive analytics dashboard (`tokens-dashboard`) for real-time ROI and cost tracking.
- **BetForge**: Real-time sports analytics frontend and dynamic odds computation sandbox. Delivers in-play market pricing, interactive bet slip state management, cash-out settlement workflows, and sandbox simulation against live odds feeds.
- **God's Eye View**: Interactive 3D geospatial intelligence platform rendering real-time spatial telemetry on a photorealistic digital globe. Aggregates live orbital satellites, commercial aircraft, maritime vessels, seismic activity, and open-source spatial data with a tactical HUD.
- **StealthMatrix**: Self-hosted Telegram e-commerce store bot with native Telegram Stars payment processing. Features product catalog browsing, input sanitization middleware, automated order fulfillment, and real-time inventory management.

### Cloud Infrastructure & Security Sandboxes
- **terraform-aws-bootstrap**: Modular, secure-by-default AWS infrastructure deploying an isolated VPC across two AZs, a private-subnet EC2 instance accessible via SSM Session Manager, and an encrypted S3 bucket with Checkov and TFLint verification.
- **k8s-app-delivery**: Kubernetes GitOps application delivery sandbox featuring multi-stage container builds, liveness/readiness probes, and static security analysis in CI.
