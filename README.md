## Open-Source Public Repositories

Publicly maintained tools and runtimes available on GitHub:

### [AuraTorrent](https://github.com/BiosSystem/AuraTorrent)
![Type](https://img.shields.io/badge/Type-Public_OSS-00FF72?style=flat-square)
![Stack](https://img.shields.io/badge/Stack-Vue_3_%7C_Vite_%7C_Pinia_%7C_TypeScript-blue?style=flat-square)
![Platform](https://img.shields.io/badge/Platform-PWA_%7C_Docker-orange?style=flat-square)

Responsive Vue 3 Progressive Web Application (PWA) built as a modern WebUI replacement for qBittorrent.
- **RSS Automation Hierarchy**: Drag-and-drop feed organization with custom regex download rules.
- **Multi-Daemon Switcher**: Concurrent status polling and instant switching across multiple remote qBittorrent instances.
- **Webhook Notifications**: Native Telegram Bot dispatcher pushing transfer completion alerts.
- **Hardened Client Security**: Clamped route redirection guards, origin isolation, and zero query-string credential persistence.

### [Winnow](https://github.com/BiosSystem/Winnow)
![Type](https://img.shields.io/badge/Type-Public_OSS-00FF72?style=flat-square)
![Stack](https://img.shields.io/badge/Stack-PowerShell_%7C_WPF_%7C_Windows_Sandbox-blue?style=flat-square)
![Platform](https://img.shields.io/badge/Platform-Windows_10_%2F_11-orange?style=flat-square)

Modular PowerShell debloat, privacy enforcement, and workstation provisioning toolkit for Windows 10 and 11.
- **Non-Destructive Audit Mode**: Dry-run inspection reports every registry, service, and Appx package diff prior to execution.
- **Granular System Controls**: Targeted removal of OS telemetry, background scheduled tasks, and preinstalled consumer packages.
- **Portable JSON Profiles**: Versioned configuration export and import for repeatable unattended workstation setups.

### [retro-game-replicas](https://github.com/BiosSystem/retro-game-replicas)
![Type](https://img.shields.io/badge/Type-Public_OSS-00FF72?style=flat-square)
![Stack](https://img.shields.io/badge/Stack-Tauri_v2_%7C_Phaser_%7C_TypeScript_%7C_Rust-blue?style=flat-square)
![Platform](https://img.shields.io/badge/Platform-Desktop_Runtime-orange?style=flat-square)

*BiosSystem Neon Arcade*: Cross-platform desktop arcade launcher, custom vector pipeline, and sandboxed game runtime.
- **11 Arcade Recreations**: Deterministic 60 FPS game loops with procedural WebAudio synthesis.
- **GLSL CRT PostFX Pipeline**: Hardware-accelerated scanlines, shadow masks, barrel distortion, and phosphor bloom with shader bounds clamping.
- **Sandboxed Bytecode VM**: Built-in cartridge player scene and modding SDK with strict Tauri IPC capability scopes.

### [OriginalMS](https://github.com/BiosSystem/OriginalMS)
![Type](https://img.shields.io/badge/Type-Public_OSS-00FF72?style=flat-square)
![Stack](https://img.shields.io/badge/Stack-Java_8_%7C_Apache_MINA_%7C_MySQL_%7C_Docker-blue?style=flat-square)
![Platform](https://img.shields.io/badge/Platform-Server_Emulator-orange?style=flat-square)

Containerized MapleStory v62 (GMS 2008) server emulator built on Apache MINA asynchronous network sockets.
- **Full Progression & Encounter Scripts**: Working party quests (KPQ, LPQ, OPQ, CWKPQ), boss state machines (Zakum, Horntail, Pink Bean), Cygnus Knights, and Aran job advancements.
- **Non-Blocking Socket Engine**: Event-driven packet framing across login, world, and channel server nodes.
- **Containerized Deployment**: Multi-service Docker Compose topology with automated MySQL schema andWZ data initialization.

## Core Private Systems & Infrastructure Portfolio

Production platforms, network daemons, and cloud infrastructure engineered and operated within the private BiosSystem environment:

### Network Daemons & High-Concurrency Platforms

#### Steady - Network Throughput & Tail-Latency Console
![Domain](https://img.shields.io/badge/Domain-Network_Diagnostics-00FF72?style=flat-square)
![Stack](https://img.shields.io/badge/Stack-React_19_%7C_FastAPI_%7C_SQLite_WAL_%7C_Docker-blue?style=flat-square)

Self-hosted network performance, bufferbloat, and bandwidth benchmarking appliance for NAS and homelab links.
- **Zero External Telemetry**: Standalone measurement engine operating without third-party speedtest servers or external rate limits.
- **Tail-Latency & Jitter Profiling**: Captures download/upload throughput, unloaded ping, loaded latency under saturation (p95/p99), jitter, and UDP packet loss.
- **Time-Series Persistence**: Automated cron measurement scheduler writing historical link telemetry to SQLite in WAL mode.

#### TorrentsTracker - Private BitTorrent Announce Engine & Portal
![Domain](https://img.shields.io/badge/Domain-BitTorrent_Infrastructure-00FF72?style=flat-square)
![Stack](https://img.shields.io/badge/Stack-NestJS_%7C_Next.js_%7C_PostgreSQL_%7C_Prisma-blue?style=flat-square)

Invite-only private BitTorrent tracker platform built on an end-to-end TypeScript architecture.
- **High-Throughput Announce Daemon**: Dedicated NestJS announce and scrape service managing concurrent peer swarms, passkey validation, and IP rate limiting.
- **Member Catalog & Ratio Ledger**: Next.js App Router frontend with torrent indexing, live seeder/leecher peer tables, and automated upload/download credit accounting in PostgreSQL.

#### BetForge - Real-Time Sportsbook Pricing & Bet-Slip Engine
![Domain](https://img.shields.io/badge/Domain-Financial_%26_Odds_Modeling-00FF72?style=flat-square)
![Stack](https://img.shields.io/badge/Stack-React_18_%7C_TypeScript_%7C_Vite_%7C_Tailwind-blue?style=flat-square)

Sportsbook frontend and real-time market odds computation platform.
- **Dynamic Market Conversion**: Instantaneous pricing recalculation across decimal, fractional, and American odds formats.
- **Combinatorial Bet-Slip State Machine**: Supports singles, accumulators, and full system permutation slips (Trixie, Yankee, Goliath) with live cash-out valuation.

### Systems Control Planes, Hardware & Telemetry

#### AuraOS & BiosPortal - Self-Hosted Cloud & NAS Control Plane
![Domain](https://img.shields.io/badge/Domain-Systems_%26_NAS_Gateway-00FF72?style=flat-square)
![Stack](https://img.shields.io/badge/Stack-Go_%7C_Echo_%7C_FastAPI_%7C_React_19_%7C_ZFS-blue?style=flat-square)

Unified cloud portal and custom Go/Echo operating gateway managing self-hosted NAS infrastructure.
- **Host & Storage Orchestration**: REST control plane over Docker container lifecycles, ZFS pool health, and mDNS local mesh routing.
- **Defense-in-Depth Gateway**: 7-layer FastAPI security middleware enforcing OAuth2, TOTP 2FA, SSRF-safe media proxying, and sliding-window rate limits.

#### Therm Studio - USB Hardware Telemetry & LCD Compositor
![Domain](https://img.shields.io/badge/Domain-Hardware_Telemetry-00FF72?style=flat-square)
![Stack](https://img.shields.io/badge/Stack-Python_%7C_FastAPI_%7C_TypeScript_%7C_USB_HID-blue?style=flat-square)

Local-first hardware sensor engine and 320x320 USB CPU-cooler LCD frame compositor.
- **Direct USB Frame Transport**: Streams layered gauge scenes, live thermal graphs, and media buffers directly to USB LCD controllers without vendor bloatware.
- **Rule & Alert Engine**: Configurable thermal thresholds and local REST webhooks for streamer and workstation automation.

#### StatZilla & Geospatial Telemetry Engines
![Domain](https://img.shields.io/badge/Domain-Real--Time_Telemetry-00FF72?style=flat-square)
![Stack](https://img.shields.io/badge/Stack-React_19_%7C_TypeScript_%7C_Cesium_%7C_WebGL-blue?style=flat-square)

- **StatZilla**: Mobile esports analytics PWA aggregating live player battle logs, win-rate distributions, and club leaderboards from official Supercell and PUBG APIs via a key-safe caching proxy.
- **3D Orbital & Aviation Globe**: WebGL and Cesium spatial intelligence globe tracking live orbital satellite TLEs, ADS-B commercial aviation, AIS maritime vessels, and seismic feeds.
